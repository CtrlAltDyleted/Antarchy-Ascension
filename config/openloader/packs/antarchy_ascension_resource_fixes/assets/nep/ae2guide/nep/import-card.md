# Import Card

The Not Enough Patterns Import Card is disabled in Antarchy - Ascension. Use AE2 Helpers' [Crafting Result Import Card](/ae2helpers/result_import_card.md) instead.

<ItemImage id="ae2helpers:result_import_card" scale="2"/>

<RecipeFor id="ae2helpers:result_import_card"/>

The AE2 Helpers card has its own settings for importing only crafting results, syncing with the crafting CPU, and choosing the import side. Read its [configuration and limitations](/ae2helpers/result_import_card.md) before using it with a provider.
